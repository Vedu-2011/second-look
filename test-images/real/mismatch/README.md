# The wrong pill

Add `label.jpg`: the fictional ibuprofen 200 mg label from `/labels`, default NDC 0113-0517. Add `pill.jpg`: one real acetaminophen 500 mg tablet with imprint L484, letters facing up on a plain surface in good light. Do not put a wrong pill into any bottle used for actual medicine.

Use the fictional patient Alex Rivera and exclude real patient details. Photos will be public. Run `npm run samples:build` to apply orientation, resize, remove EXIF, run the live checker, and save images/results. Commit generated files. Both photos are required; an empty folder retains the recorded FDA example.
