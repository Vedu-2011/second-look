# Same medicine, new look

Add `label.jpg`: the fictional Advil (ibuprofen) 200 mg label from `/labels`, default NDC 0573-0160, Haleon. Add `pill.jpg`: one store-brand ibuprofen 200 mg pill, such as orange oval I2, letters facing up on a plain surface in good light. The medicine and strength must agree but the maker/appearance differs.

Use only Alex Rivera as the fictional patient; no real patient details. Photos will be public. Run `npm run samples:build` to orient, resize, strip EXIF, run the live checker, and save photos/results. Commit generated files. Both photos are required; empty folders retain the recorded FDA example.
